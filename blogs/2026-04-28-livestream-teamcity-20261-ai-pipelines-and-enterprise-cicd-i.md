<p>TeamCity 2026.1 introduces a set of focused improvements that make your CI/CD more intuitive, intelligent, and enterprise-ready.</p>



<p>Join us for a live walkthrough of the latest updates, including support for both the Kotlin DSL and YAML in pipelines.</p>



<figure class="wp-block-image size-full"><img alt="" class="wp-image-704030" src="https://blog.jetbrains.com/wp-content/uploads/2026/04/introducing-teamcity-20261-livestream-image.png" style="width: 100% !important; height: auto !important;" /></figure>



<p>We’ll also introduce the new TeamCity CLI, which includes agent skills for popular AI coding agents like Claude Code, Codex, and JetBrains Junie. The TeamCity CLI helps developers run and manage TeamCity commands directly from the terminal. With added MCP support, it also connects TeamCity to leading AI tools across different environments.</p>

<p>We’ll share how these changes fit into TeamCity’s broader evolution, including AI-assisted workflows and a more flexible pipeline experience, and what’s coming next on our roadmap.</p>



<p>Whether you’re already using TeamCity or exploring modern CI/CD approaches, this session will give you practical insights and a look at where TeamCity is heading.</p>

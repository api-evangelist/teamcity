<p>Our final bug-fix update for the 2025.11 On-Premises servers is now available. Version 2025.11.4 addresses a few issues, including the folowing:</p>



<ul>
<li>Bitbucket Cloud connection issues related to <a href="https://developer.atlassian.com/cloud/bitbucket/changelog/#CHANGE-3139" rel="noopener" target="_blank">Atlassian deprecating older APIs</a>; </li>



<li>Unresolved output parameters causing the build to fail;</li>



<li>Excessive Git operations on changes checking;</li>



<li>VCS problems causing performance issues.</li>
</ul>



<p>All TeamCity bug-fix updates include performance and security improvements, so we recommend that you never skip these minor updates. See <a href="https://www.jetbrains.com/help/teamcity/teamcity-2025-11-4-release-notes.html" rel="noopener" target="_blank">TeamCity 2025.11.4 Release Notes</a> for the complete list of resolved issues.</p>



<h3 class="wp-block-heading"><strong>Why update?</strong></h3>



<p>Staying up to date with minor releases ensures your TeamCity instance benefits from the following:</p>



<ul>
<li>Performance improvements.</li>



<li>Better compatibility with integrations.</li>



<li>Faster, more stable builds.</li>



<li>Enhanced security for your workflows.</li>
</ul>



<p>This update is also crucial for teams utilizing Bitbucket Cloud connections in TeamCity, as they no longer function as expected due to changes in Bitbucket API.</p>



<h3 class="wp-block-heading"><strong>Compatibility</strong></h3>



<p>TeamCity 2025.11.4 shares the same data format as all 2025.11.x releases. You can upgrade or downgrade within this series without the need for backup and restoration.</p>



<h3 class="wp-block-heading"><strong>How to upgrade</strong></h3>



<ol>
<li>Use the <strong>automatic update</strong> feature in your current TeamCity version.</li>



<li>Download the latest version directly from the <a href="https://www.jetbrains.com/teamcity/download/" rel="noopener" target="_blank">JetBrains website</a>.</li>



<li>Pull the updated TeamCity Docker image.</li>
</ol>

Summary Details A high-severity post-authentication security vulnerability has been identified in TeamCity On-Premises. If exploited, this flaw may allow any authenticated user to expose some parts of the TeamCity server API to unauthorized users. All versions of TeamCity On-Premises are affected, while TeamCity Cloud is not affected and requires no action.
